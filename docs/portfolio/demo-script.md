# Two-to-four-minute demo script

1. Register, complete onboarding, and point out local-only AI privacy plus the
   implementation intention.
2. Open Today: show the 30-minute FocusOrb, Core/Recovery distinction, optional
   Stretch, three nested knowledge checks, task subtasks, and official resource
   trail.
3. Start Core, save explicit evidence and a reflection draft, then complete.
   Show XP/reviews/skills derived from evidence rather than clicks.
4. Open Roadmap, JourneyMap, MomentumOrbit, Skills, Code Garden, and the Error
   Museum. Explain no-shame catch-up and intentional skip.
5. Index one private note. Ask one supported and one unsupported question; open
   citations and show abstention.
6. Run the coach in mock/Python-mock mode. Point out generated labeling,
   privacy consent, trace metadata, and fallback.
7. Create a weekly plan and show that approval is required before save.
8. Run local evals and show zero estimated provider cost.
9. End with architecture, the real-Mongo isolation tests, and account deletion.

Use synthetic data only. Do not record an API key, email inbox, filesystem
secret, or personal reflection.
